# Averlo · Animate

Direct a reviewed static surface as a readable sequence, not a collection of
entrance wrappers. Preserve the accepted motion-off endpoint exactly.

## Start from the accepted static target

1. Require a schema-v2 `.template-profile.json` receipt, an explicit user
   request for animation, and a current native static Target. Read
   `$averlo:visual-parity`'s focus packet and freeze the accepted motion-off
   endpoint.
2. Use `$averlo:visual-parity` to verify motion-off, reduced-motion, and settled
   motion-on endpoints against the accepted static capture. These comparisons
   prove endpoints, not intermediate frames.
3. Invoke `$averlo:repository-workflows` once before implementation. Select
   Interaction plus every actual composition, shell, catalogue, route, or
   performance concern affected by the motion.

## Direct the movement

1. State one motion thesis and a compact map for the effective scope: reading
   order, primary progression, supporting vocabulary, stillness, compact
   treatment, reduced-motion behavior, and owner.
2. Inventory existing motion owners and approved Storybook compositions whose
   literal `parameters.motionComposition` has `status: "approved"`. Reuse one
   only when the current static hierarchy, semantic roles, and ordering match
   its `staticPattern` after product copy and assets are removed.
3. Otherwise choose the smallest existing individual-effect vocabulary that
   makes the thesis legible. Suggest a new neutral composition candidate when a
   repeated arrangement needs coordination that existing effects cannot express;
   do not add a scheduler, observer, reset system, or timing family locally.
4. Preserve input agency, focus, keyboard behavior, reduced motion, real initial
   DOM content, and compact-layout intent. Measure scroll-linked work before
   accepting it.

## Promote evidence

After successful local motion, add or update a neutral instance Storybook
fixture with literal `parameters.motionComposition` metadata and the
`backport-candidate` lifecycle used by `$averlo:storybook-backport`. It remains
a candidate until human approval and is not transferred to the canonical
template here.

Verify normal playback, re-entry, interruption, resize, narrow widths,
motion-off, reduced motion, and settled motion-on. Report endpoint parity,
playback findings, Storybook evidence, and any instance-local choreography.
