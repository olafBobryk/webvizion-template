# Averlo · Composition Convergence

Close the remaining source difference without reopening architecture casually.
This plane owns source-comparison interpretation, scoped correction turns,
stall counts, responsive revalidation, and exact static completion.

## Require the integrated handoff

1. Read [Compose's record contract](../compose/references/composition-record.md).
   Require Realization and Integration handoffs `ready`, every affected
   Integration parity row at zero, complete owner evidence, and current
   post-integration source measurements. Return a missing owner or incomplete
   migration to System Integration instead of patching around it locally.
2. Reuse Compose's active goal. For a direct invocation, call `get_goal` and
   create one plane-scoped goal only when needed:

   ```text
   Invoke $averlo:composition-convergence to continue <record-path> to its exact source-backed terminal condition.
   ```

3. Set Active plane to `composition-convergence` and Convergence handoff to
   `active`. Invoke `$averlo:repository-workflows` only for concerns affected by
   the correction and `$averlo:visual-parity` for reproducible evidence.

## Correct one scope per turn

1. Select one `mismatched` or `stale` source-backed row in matrix order, set it
   `active`, and address its highest-impact Target-owned differences. One turn
   owns one scope but may make and measure as many related changes as useful; it
   is not restricted to one hypothesis or one edit.
2. Before Target edits, mark affected measured rows and the full-page gate
   `stale`. Make repeated or owner-overlapping visual corrections through their
   integrated owners. Content, exact assets, unique geometry, and choreography
   may remain local.
3. When a correction reveals an unrecorded repeated or owner-overlapping role,
   do not create a local escape. Record the owner gap, set Integration handoff
   to `pending`, preserve the current source metrics, and return control to
   Compose for a render-preserving System Integration pass.
4. Capture with motion disabled and run `$averlo:visual-parity` in `verify`.
   Interpret raw comparability, dimensions, changed pixels, mean channel delta,
   capture identity, native evidence, and artifacts. `comparable: false` is a
   capture defect or blocker, never completion.

## Continue until exact or truly stalled

Set a source-backed row to `exact` only when it is comparable, current, native,
and reports `changedPixels: 0`. Every comparable nonzero row remains
`mismatched`, even when visually close.

After the turn's final assessment, reset Non-improving turns when changed pixels
or mean delta improves over the preceding comparable assessment. Otherwise
increment it once. A pure recapture with the same Target SHA-256 and no
Target-owned work neither increments nor resets it. Any improving nonzero result
is actionable: update the record, leave the goal active, and continue on the
next turn. Never end the workflow merely because the result is close.

At three consecutive non-improving correction turns for one scope, mark that
row `blocked` and continue independent actionable rows. Block the record and
goal only when no actionable work remains and a blocked row prevents exact
completion. Report the best evidence and concrete incapability; never waive
renderer noise or convert it into an accepted exception.

A nonzero full-page result reopens the smallest owning scope, then returns to
the full-page gate. Once all source-backed rows are exact, rerun the entire
matrix against the current Target identity, then verify Target-only responsive
cases at 390, 768, 1024, and 1440 pixels, repository checks, native evidence,
promoted artifacts, and current Preview human-review evidence.

Set Convergence handoff to `exact`, Active plane to `complete`, and Overall
state to `complete` only after all terminal evidence is current. For a direct
plane goal, call `update_goal` with `complete`. Under Compose, return control so
it can complete the shared static goal or continue to explicitly requested
motion.
