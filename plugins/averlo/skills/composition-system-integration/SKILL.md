# Averlo · Composition System Integration

Turn one complete realized surface into one coherent instance design system.
This plane owns role census, owner migration, subtractive retirement, consumer
adoption, catalogue evidence, and target-to-target render preservation.

## Require the realization handoff

1. Read [Compose's record contract](../compose/references/composition-record.md).
   Require Realization handoff `ready`, complete source decomposition, native
   evidence, and current realization captures. Do not fill missing source or
   implementation work on this plane; return the record to Realization.
2. Reuse Compose's active goal. For a direct invocation, call `get_goal` and
   create one plane-scoped goal only when needed:

   ```text
   Invoke $averlo:composition-system-integration to complete the render-preserving owner migration in <record-path>.
   ```

3. Set Active plane to `composition-system-integration`, Integration handoff to
   `active`, and freeze each affected realization Target capture and SHA-256 as
   its Integration parity reference before the first Target edit.
4. Invoke `$averlo:repository-workflows` for owner discovery, composition,
   marketing/shell, catalogue, route, and media concerns selected by the actual
   change unit.

## Build the one system

1. Census every visible typography, control, link, mark, media, shell, and
   repeated layout role across the complete focus. Compare it with every
   documented owner, variant, consumer, and inherited recipe. Write the complete
   Owner migration table at exact owner-axis or role granularity before edits.
2. Apply owner precedence. A role inside an existing owner's domain migrates
   through that owner. A repeated role without an owner gains a source-neutral
   owner. Repetition or owner overlap can never be escaped as `instance-local`.
3. Scope Source authority to the evidenced axis. Repeated horizontal gutters
   may replace Section `px`; section-specific `py` stays local; unevidenced
   `maxWidth`, responsive, structural, or behavioral axes remain
   `unevidenced-preserve` and are never claimed converted.
4. Assign each row exactly one disposition: `replace`, `merge-retire`,
   `source-supported-retain`, `unevidenced-preserve`, or `instance-local`.
   Restrict `instance-local` to content, exact constituent assets, unique
   geometry, and choreography that neither overlap an owner nor repeat.
5. Make migration subtractive. Move the evidenced visual recipe and all current
   consumers to the resulting owner; remove the superseded inherited or
   page-local recipe. A semantic wrapper that still receives the complete visual
   recipe from route-local classes is not a migrated visual owner.
6. Every genuine typography role becomes a source-neutral instance-wide `Text`
   variant after comparing its complete type signature and purpose with all
   current variants and consumers. Update its contract and exhaustive Storybook
   scale in the same change. Apply equivalent owner and catalogue evidence to
   actions, logos, sections, and other evidenced roles.

## Preserve the realized render

After each owner migration, use `$averlo:visual-parity` to compare the pinned
realization Target image with the integrated Target at identical capture
conditions. Record it in Integration parity. This comparison proves refactor
preservation; it is not a Figma/source parity claim.

An affected scope is integration-exact only at `changedPixels: 0`. An
improvement against Figma cannot compensate for a target-to-target difference.
Correct any integration-introduced difference before continuing. Once every
owner row has current consumers, retired recipes, contracts, catalogue and
Storybook evidence, and every affected Integration parity row is exact, refresh
the Figma-versus-current-Target measurements and native evidence.

Set Integration handoff to `ready` and Active plane to
`composition-convergence`. Preserve nonzero source rows as `mismatched`; never
call them verified. For a direct plane goal only, call `update_goal` with
`complete`. Under Compose, leave its goal active and return control.
